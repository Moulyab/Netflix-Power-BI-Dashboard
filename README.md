# Netflix Movies & TV Shows Data Analysis Dashboard

## Project Overview

This project analyzes Netflix Movies and TV Shows data using Power BI.

The dashboard provides interactive visualizations to understand content
distribution, countries, genres, ratings, and content trends over time.

##  Tools & Technologies

- Power BI
- Python
- Data Analysis
- Data Visualization

##  Dashboard

[Netflix Data Analysis Dashboard](netflix-dashboard.png)

##  Key Insights

- Compared Movies and TV Shows available on Netflix
- Analyzed the top countries by number of titles
- Examined content added over the years
- Analyzed content ratings
- Explored popular genres
- Displayed the total number of Netflix titles
